Website split structure
=======================

This version keeps the homepage as:
- Hero/Profile header
- News section
- About section

The remaining sections are independent pages:
- education.html
- publications.html
- teaching.html
- activities.html

Navigation behavior:
- Home opens index.html
- News and About point to anchors inside index.html
- Education, Publications, Teaching, and Activities open their own HTML files

Keep these HTML files in the same directory as your existing assets:
css/, js/, scripts/, images/, flags/, files/, and my_cv.pdf
